# Portfolio profesional — Fernando Garín Tejedor

Sitio responsive construido con Astro, TypeScript y CSS propio, preparado para GitHub Pages.

## Completar antes de publicar

- Cambiar `fernando@example.com` por el email real.
- Agregar los enlaces reales de LinkedIn y GitHub.
- Copiar el CV como `public/cv/Fernando-Garin-Tejedor-CV.pdf`.
- Revisar experiencia y proyectos con la información del perfil de LinkedIn.

## Ejecutar

```bash
npm install
npm run dev
```

## Publicar

Subir a la rama `main`. En GitHub, ir a **Settings → Pages** y seleccionar **GitHub Actions** como fuente. El workflow incluido compila y publica automáticamente cada cambio.
